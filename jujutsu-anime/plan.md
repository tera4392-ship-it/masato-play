# 呪術廻戦 二次創作 3Dショートアニメ 企画書(たたき台)

> 非商用のファン作品。原作のセリフ・場面の転載はせず、オリジナルの短編シーンとして構成する。

## 1. 企画概要
- タイトル(仮): **「黒閃、ひとつ分」**
- 尺: 約60秒(12カット)
- 形式: three.js のブラウザ3Dアニメ(後でmp4書き出しも可能)
- 見せ場: 虎杖悠仁の打撃が「黒閃」に昇華する一瞬(空間が歪み、黒と赤の火花が走る)
- 登場: 虎杖悠仁、伏黒恵(サポート)、オリジナル呪霊1体
- 舞台: 夜の廃校舎の中庭(低ポリで作りやすく、暗い背景が黒閃の演出に映える)
- トーン: 静→溜め→爆発→余韻。セリフはほぼ無し、音と間で見せる

## 2. 脚本(ワンシーン)
1. 夜の中庭。月明かり、風で揺れる草。呪霊が地面からせり上がる。
2. 伏黒が式神(玉犬)を出して牽制するが、呪霊の腕で弾き飛ばされる。
3. 虎杖が前に出る。呪霊の連撃を紙一重でかわし続ける。
4. 一瞬、時間が止まったように音が消える。虎杖の拳に黒い火花が走り始める。
5. 踏み込み。拳が当たる直前、画面が黒く歪み、赤い稲妻が走る(黒閃)。
6. 呪霊が吹き飛び、校舎の壁に激突。粉塵。
7. 静寂。虎杖が拳を見つめ、伏黒が「…今のは」と小さくつぶやく。暗転、タイトル。

## 4. 3D制作方針
- **キャラ**: 低ポリ+トゥーンシェーディング+アウトライン(three.js の `MeshToonMaterial` + 輪郭は裏面法線拡大)。顔は簡略化し、髪型・服のシルエットで識別できるように。
- **アニメーション**: ボーン無しのパーツ階層(胴・腕・脚)をコードで補間。かわし・踏み込み・殴りはキーフレーム配列で管理。
- **黒閃の表現**: ポストプロセスで色収差+歪み、黒い球状シェーダ、赤いライン状パーティクル。ヒット時に1〜2フレだけ白黒反転。
- **カメラ**: カット毎にキーフレームを定義、`timeline` で再生/一時停止/シーク可能に。
- **音**: Web Audio API で簡易SE(風、衝撃、無音)。BGMは後から差し替え。
