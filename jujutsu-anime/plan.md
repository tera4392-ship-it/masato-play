# 呪術廻戦 二次創作 3Dショートアニメ 企画書(v3)

> 非商用のファン作品。原作のセリフ・場面の転載はせず、オリジナルの短編シーンとして構成する。

## 1. 企画概要
- タイトル(仮): **「八頭、ひとつ分」**
- 尺: 約75秒(14カット)
- 形式: three.js で描画し **mp4(1280x720 / 24fps)に書き出し**(YouTube公開用)
- 登場: 虎杖悠仁、伏黒恵、式神の **鵺**(雷)と **玉犬・渾**(白と黒が合体した大型の1頭)、敵のオリジナル呪霊
- 敵: **ヤマタノオロチ型の呪霊**。**首は3本**(赤・黄・青の目)、胴の前面に赤い核がある。
- 舞台: 夜の廃校舎の中庭(暗い背景で雷と黒閃が映える)
- 流れ: 対峙 → 鵺の雷 → 玉犬と伏黒の打撃 → 虎杖の黒閃でトドメ
- トーン: 静→連携で畳みかける→一撃→余韻。セリフはほぼ無し。

## 2. 脚本
1. **対峙**: 夜の中庭。霧の中から3本の首をもたげた呪霊が現れ、虎杖・伏黒が並んで立つ。
2. **鵺の雷**: 伏黒が式神を呼ぶ。鵺が舞い上がり、呪霊の首へ雷を落とす。首が数本のけぞる。
3. **玉犬+伏黒の打撃**: 玉犬・渾が首の根元に噛みつき、伏黒が懐に入って打撃を重ねる。呪霊の首が一瞬バラけ、胴の中心が開く。
4. **溜め**: 虎杖が前に出る。無音。拳に黒い火花が走り始める。
5. **黒閃**: 踏み込み、拳が胴の中心に入る瞬間、画面が歪み、黒と赤の稲妻が走る。
6. **決着**: 3本の首が連鎖的に崩れ、粉塵。静寂。虎杖が拳を見つめ、伏黒と式神が並ぶ。暗転、タイトル。

## 4. 3D制作方針
- **キャラ**: 低ポリ+トゥーンシェーディング+アウトライン(`MeshToonMaterial` と裏面法線拡大の輪郭)。髪型・服のシルエットで識別できるように。
- **鵺**: 翼を広げた大きな鳥型。羽ばたきと、体から走る雷のライン(発光ポリライン)を表現。
- **玉犬・渾**: 白黒の大型1頭。四足の簡易歩行サイクルと噛みつきポーズ。
- **ヤマタノオロチ型呪霊**: 首は球を連ねた蛇行チェーンで、位相をずらした波で動かす。3本は同一ロジックで首ごとに目の色と長さを変える。
- **アニメーション**: ボーン無しのパーツ階層をコードで補間し、キーフレーム配列で管理。
- **黒閃**: ポストプロセスで色収差+歪み、黒い球状シェーダ、赤いライン状パーティクル。
- **雷**: 枝分かれする発光ライン+ブルーム+画面フラッシュ。黒閃の赤黒と色で差別化する。
- **カメラ**: カット毎にキーフレームを持つタイムライン。再生/一時停止/シーク可能。
- **音**: Web Audio API の簡易SE(雷、打撃、無音、黒閃の衝撃)。

## 7. 制作・書き出し手順
```
cd jujutsu-anime && npm install
node render.cjs <開始秒> <終了秒> out/xxx.mp4 24   # 動画
node render.cjs 53.1 53.1 out/frame.jpg             # 1フレーム確認
```
ブラウザで `index.html` を開くとリアルタイムのプレビュー(`?from=42` で開始秒、`?t=53.1` で静止)ができる。
