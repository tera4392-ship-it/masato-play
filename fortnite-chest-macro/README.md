# フォートナイト 宝箱オープン・マクロ (撮影用)

宝箱を開け続ける AutoHotkey v2 スクリプトです。Windows PC 用。

## 使い方
1. [AutoHotkey v2](https://www.autohotkey.com/) をインストール
2. `chest_macro.ahk` をダブルクリック (**フォートナイトより先に起動し、管理者として実行**すると入力が届きやすい)
3. 宝箱の前に立ち、**F8** で開始 / もう一度 **F8** で停止
4. **F9** で緊急終了 (押しっぱなしのキーも自動で解除)

## 調整 (ファイル上部の設定)
| 設定 | 意味 |
|---|---|
| `HoldMs` | Eを押し続ける時間。宝箱が開かない場合は増やす (1300→1600) |
| `GapMs` | 次の動作までの間隔 |
| `JitterMs` | ランダムなゆらぎ (人の操作っぽく見せる) |
| `WalkEnabled` | `true` で開けた後に前進。宝箱が並んでいる場面向き |
| `InteractKey` | ゲーム内の「操作」キーを変えている場合に変更 (`sc012` = E) |

## 撮影時のコツ
- 本番前に、**ゲーム内で宝箱を開ける時間を測って** `HoldMs` を合わせる
- 宝箱が多いエリアで `WalkEnabled := true` にすると連続して開けていく絵が撮れる
- 画面録画 (OBS 等) は、マクロ開始前に回しておく
- 万一ズレたらすぐ **F8** で止める

## 注意
- フォートナイトは Easy Anti-Cheat を使っています。**入力を自動化するツールは規約上グレーで、アカウント制限の可能性がゼロではありません。** 撮影は**クリエイティブ / プライベートマッチ、サブアカウント**で行うのが安全です。
- 他人が参加するマッチでの長時間の放置使用は避けてください。
