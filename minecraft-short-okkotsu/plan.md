# もし乙骨憂太と鹿紫雲一が戦ったらどうなる?(企画書 v1)

> 非商用のファン作品。マイクラ風の見た目はドット絵を自作し、Mojangの素材・ロゴは使わない。

## 1. 仕様
- 形式: YouTubeショート(縦 1080x1920 / 30fps / mp4)、**約60秒**
- 前作からの変更点(今回の方針)
  - **テンポを速く**: 1カット平均2.5秒、余白(無音・溜め)を最小限にする
  - **エフェクトを増やす**: 雷・衝撃波・ボクセル破片・集中線・画面フラッシュ・ヒットストップを常時入れる
  - **カメラワーク重視**: 回り込み(オービット)、急速なドリーイン、煽り/俯瞰、ウィップパン、背後からの追従、決め場面のスローモーション
- 見た目: マイクラ風ブロックキャラ+ブロックの遊園地
- 解説: 画面**上部**のテロップ。ライフ(ハート)は画面**下部**
- 音: 効果音は自作(雷・打撃・爆発など)。BGMなし。音声(ナレーション)は台本ができたら別途入れる
- 冒頭のタイトル字幕・黒背景はなし(動画タイトルはYouTube側で付ける)。最後に1.5秒ほどの問いかけエンドカード

## 2. 登場キャラと舞台
- **乙骨憂太**: 黒髪、白い制服、刀。
- **リカ(特級過呪怨霊)**: 白い巨大なブロックの怪物。大きな両手と、赤い牙の口。完全顕現では一回り大きくなり、鎖と光輪が増える。
- **鹿紫雲一**: 水色の髪、白い装い、頬の雷模様。体から雷を放つ。幻獣琥珀を発動すると、体が金色の雷そのものになる。
- **舞台: 夕暮れの遊園地**。観覧車、ジェットコースター、メリーゴーランド、テント、ゲートをブロックで作る。雷や爆発で観覧車が光り、壊れていく演出で派手さを出す。

## 4. 制作方針
- **キャラ追加**: 乙骨、鹿紫雲(ドット絵テクスチャ)、リカ(白い巨大な怪物。通常と完全顕現の2サイズ)。
- **遊園地**: 観覧車(回転、光る)、ジェットコースター、メリーゴーランド、テント、ゲート、ネオン。
- **エフェクト**: 雷(枝分かれ)、衝撃波リング、ボクセル破片、集中線、画面フラッシュ、ヒットストップ、白黒反転、残像。
- **カメラ**: オービット、ドリー、ウィップパン、背後追従、煽り、俯瞰を、各カットで切り替える。
- **ライフ**: 画面下にハート。乙骨と鹿紫雲の両方を出し、ヒットで減る。
- **効果音**: 雷、打撃、斬撃、結界、爆発、貫通などを自作。

## 5. 確認したいこと
1. 領域の名前は、前作と同じく画面に出さず「領域展開」だけにしますか。それとも「真贋相愛」と出しますか。
2. 乙骨が死亡する場面(#20〜21)は、ブロックキャラが倒れるだけの表現にします。ゴアな表現はしません。それでよいですか。
3. 最後のエンドカードは入れますか。
4. 音声(ナレーション)は、この動画にも入れる予定ですか。入れる場合は、台本を先にもらってから秒数を調整します。
